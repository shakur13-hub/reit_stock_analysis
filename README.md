REIT Stock Analysis

Project Overview
This project explores the financial performance of Real Estate Investment Trust (REITs) using Python. The analysis focuses on stock price data, statistical relationships and risk-return characteristics to better understand how REIT investments behave over time.

Objectives
Analyse historical REIT stock price data.
Calculate and compare stock returns
Examine covariance to understand how REIT returns move in relation to one another.
Explore relationships between different REIT stocks to support portfolio analysis
Apply Python and data analysis techniques to financial market data.

Tools and Technologies
Python - data analysis and calculations
Jupyter Notebook - interactive analysis and documentation
Pandas - data manipulation and analysis
NumPy - numerical calculations

Methodology
The project uses Python to load and process REIT stock data, calculate relevant financial metrics and investigate relationships between stock returns
Covariance is used to examine whether the returns of two assets tend to move together. This provides insight into how different REIT stocks may behave when considered as part of an investment portfolio,

Key Concepts
Stock returns
Covariance 
Correlation
Financial data analysis
Portfoliio diversification

Repository Contents
Real_estate_inverment_trust_analysis.ipynb - Jupyter Notebook containing the analysis, calculations and results.

How to Run
1. Clone/download the repository
2. Install Python and Jupyter Notebook
3. Install the required libaries used in the notebook
4. Open the notebook and run the cells in sequence
